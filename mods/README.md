# Mod sources

Each folder is a mod **source tree**: the files exactly as they sit inside the
`.mod` archive. Zip the *contents* of a folder (not the folder itself) to build
one, or use `pmmod build <folder>`.

| Folder | What it is |
|---|---|
| `vanbobby-fast-strings/` | Strings mod. Faster text for repeated interactions, EN + ES. |
| `vanbobby-android-layout-fix/` | Theme mod. Fixes the "UI layout loop" on Android/handhelds. |
| `vanbobby-region-label-unpad/` | Strings mod. Restores plain region names. |
| `vanbobby-only-shiny-sprites/` | Battle sprites. Hides every non-shiny opponent. |
| `vanbobby-shiny-scale-probe/` | Throwaway test mod. Answers whether the scale tables work on ROM sprites. |
| `vanbobby-stadium-battlesprites/` | Battle sprites rendered from Pokémon Stadium 2 models. |
| `vanbobby-demo-strings/` | Two-line example showing how a strings mod is put together. |

Every folder has its own README with the full write-up.
