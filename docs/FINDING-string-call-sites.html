Which Token Works Where

Silencing a PokeMMO message is not one trick. It is three, and which one works is decided by the code that draws the box — not by the text, the table, or anything visible in the dumps.

Established on hardware · Retroid Pocket G2 · client r32920 v1.3 → v1.7 · 2026-08-30

The finding. The replacement token is a property of the call site. The same {09} that erases a field-move box outright leaves an unresolved placeholder at the battle tables — a box that sits there and visibly drags the end of a fight out. Four build–install–play cycles were spent proving this the hard way, each one reasoning from the corpus instead of reading the reference mod.

Nothing in the 30,341-entry dump distinguishes these call sites. The only way to know is to test on hardware, or to copy a mod that already has.

The three tokens

TokenWhat it isEffect
{09} An argument placeholder. Slot 9 is never filled in the tables this mod touches. Box removed — but only where the engine drops an unresolved message. Elsewhere it stalls.
\n\n An escaped newline pair — a well-formed empty message. Passes through cleanly at the battle tables. This is what SupersStrings uses.
<string/> An empty element. Not a token — the client reads it as no override and its own text comes back.

There is no fourth option. The only non-argument control codes in the entire corpus are DELAY_0F, DELAY_14, DELAY_3C, DELAY_5A and DELAY_64. The client has no close or skip code.

Tier B — highest volume, no evidence at all

one battle to settle

Table 14 is 1,159 entries and the busiest thing in the game: every stat change, every status tick, every “It's super effective!”. {09} is known to stall here. Whether \n\n passes through is simply unknown — SupersStrings does not touch this table, so there is no reference to copy.

Two things to settle before spending a cycle on it. First, whether these messages are tap-gated at all or auto-advance mid-battle — the reported symptom was always the end of a fight, which suggests the per-turn run already flows. Second, whether silencing them is even wanted: “It's super effective!” is information during a real battle and noise during a grind.

Cheapest test: blank 14/1 (“The wild {00} fainted!”) alone and win one wild battle. It answers the token question without touching anything else.

Tier C — blocked on a dump

cannot proceed

SupersStrings ships 104 overrides for the Johto archive (archive_type 0, region 4). This client has never produced that dump: the utility aborts with An invalid XML character (Unicode: 0x0) on Sinnoh and never reaches Johto.

Every region archive carries its own counters — Pokécenter, mart, Day Care — so Johto's are genuinely uncovered today, and the parity suite skips them silently rather than failing. Untried: unload the Sinnoh ROM and re-dump.

What stays readable, whatever the token

Speed is not the only axis. These are deliberate keeps, and each has already survived a review:

  • Decisions. Any box whose Yes/No leads somewhere different — 15/20 “Will you switch your Pokémon?”, 15/77 forfeit, 157/27 Mail will be lost, 157/58 already holding an item. Silencing one leaves an unlabelled prompt on a choice that costs something.
  • The level-up. 15/60 “{00} grew to Lv. {01}!” carries information the EXP number does not.
  • The battle menu. 15/69–70 “What will {00} do?” is the interface, not a message.
  • Item and move descriptions. 966 entries, ~96k characters. They look like an enormous saving if you rank by volume, but they are read on purpose. A global never guard blocks them.
  • Menu labels. A short entry with no sentence-ending punctuation is a UI label. Silencing one blanks a menu instead of skipping a box.

How to not repeat the four cycles

  • Read the reference before theorising. SupersStrings is run by thousands of people. Where it has an opinion about an address, that opinion is production evidence and it outranks anything derived from the dumps.
  • Never assume a token generalises. It is per call site. Table 8 and table 15 disagree, and they are three tables apart.
  • Scope every NDS rule to its archive. A (table, entry) pair means different text in each one — 15/45 is “Player beat {00} {01}!” in Unova and the menu label “Game Sync” in Unova-1.
  • Watch for patterns written for the GBA ids. catch-flow, evolution and move-learned all found the NDS battle tables by accident. A never_ds_tables guard now blocks that; hand-picked addresses still pass.
